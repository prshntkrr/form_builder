Security Checks
✓
Route Allowlist
22 exact regex patterns. Unrecognised paths under /api/mcdc/ return 404 before reaching any handler. No wildcards, no path traversal.
✓
Body Validation
Size limit (configurable MB cap). Must be valid JSON, must be an object. Files bypass — uploads go direct to S3 on presigned URLs.
✓
Per-Principal Throttling
Sliding-window rate limiter keyed to token + caller identity. One busy surveyor cannot exhaust another's allowance. Returns Retry-After header.
✓
Envelope Inspection
Channel name must be one of four. form_version must be integer. survey_id shape-checked. Data must be an object. Catches malformed requests early.
🔒
Idempotency Key
Shape-validated (≤64 alphanumeric chars). Never rewritten — caller controls retry identity. Namespaced by principal downstream.
🔍
Structured Logging
One log line per request: method, path, channel, principal hash, status, latency. No tokens, no form data, no PII in logs.

Uniform Error Shape & Configuration
{ "error": { "code": "RATE_LIMITED", "message": "Too many requests." }, "request_id": "a1b2c3d4..." }
Every refusal — 400, 401, 403, 404, 413, 415, 429 — returns this shape. Clients parse one format. Codes: ROUTE_NOT_ALLOWED, INVALID_REQUEST, REQUEST_TOO_LARGE, RATE_LIMITED, AUTHENTICATION_REQUIRED, FORBIDDEN.
